# salon-assistant-elisheva-paritzky

Advanced AI Engineering, lesson 1: one agent, two harnesses.

A customer assistant for a hair & makeup studio, built twice:

- `API/` – raw Messages API. The whole harness is hand-written, one file per responsibility in `API/harness/` (loop, tools, history, memory, context, compaction, caching, tokens).
- `SDK/` – Claude Agent SDK. Claude Code runs the harness; each line that replaces an API harness file is tagged `# replaces: <name>`.
- `shared/` – domain code and data used by both (tools, business data, prompt, scenario checks).
- `tests/` – offline tests with a fake client, no API key needed.
- `scenario.json` – 7 turns in 2 sessions, 8 pass/fail checks (mostly on saved state).
- `results/` – `api.json`, `sdk.json`.
- `REPORT.md` – the comparison (generated by `make_report.py`).

See REPORT.md for how to run.
